## Prompt-Set

Gemeinsame Vorgaben: eigenständige neue Bilder, Querformat 16:9, professionelle Pitch-Motive, keine Wasserzeichen. UI-Referenz als Stilvorlage, kein zu bearbeitendes Zielbild. Helle Oberflächen, dunkelblaue Typografie, blaue Bedienelemente/Routen, grüne Statusanzeigen, abgerundete Karten, ruhiger Studiohintergrund. Keine frei erfundenen Flughöhen oder Leistungskennzahlen; kein Wetterstatus als alleinige Startfreigabe. Nachfolgend die motivbezogenen Prompt-Spezifikationen; die Ausführung erfolgte auf Englisch.
